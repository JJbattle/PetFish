# 踏步动作修订：正面抬膝方向与可见幅度

2026-11-08。用户指出上一轮偏重裙下遮挡，实际关心膝盖弯折方式及抬腿幅度。本轮针对动作本身修订，正式 standing rig 的 `march` 已更新。

## 旧动作为什么像左右折腿、脚却抬不高

旧轨道是左大腿+20°/小腿−35°，右腿镜像。它们是**正面画面中的 Z 轴转角**，表现的是横向开合，不能当作向前抬膝的解剖屈曲角。两段旋转还抵消了相当部分踝抬升。

真实 Spine 峰值记录：左膝横移约27px，左踝只抬8.218px；右踝抬17.346px。按170px桌宠/820源单位折算，脚的踝点只上移约1.7/3.6屏幕像素。左右 bind pose 的髋膝偏移不同，照抄一对镜像角度不能产生相同幅度。仅改成30°/65°的独立试做，会更像侧向折腿/踢脚，故未采用。

## 本轮接法

`tools/build_spine.py` 新增 `_standing_step()`：

- 以每条腿自己的髋/膝/踝 setup 坐标求解。
- 踝目标向上55源像素、横移仅3px；默认170px桌宠中约11.4px向上、0.6px横向，左右等幅。
- 使用隐藏大腿的正面投影缩短，结合少量画面转角（大腿10°、小腿相对−22°，右腿反向）求膝骨平移；这些是2D投影修形量，不是声称人体膝关节仅屈曲22°。
- 足部反向旋转，使鞋底保持原本的画面朝向，避免抬脚时鞋跟着小腿侧翻。
- 起落加密关键帧，中间有短暂停留；2s左右交替一轮，支撑脚不加运动。
- 主腿与独立鞋共用 y885–905 的踝权重，抬脚反转鞋时切线两侧一致。
- 全部 clip 对腿旋转、膝平移、足部平移/旋转显式复位。连续混合测试发现的膝位残留已修掉。

本轮没有扩大 `heel` 的5px抬升参数；16px独立候选未采用。先解决用户正在看的踏步动作。脸、发型、服装、原鞋纹理不重新绘制。
