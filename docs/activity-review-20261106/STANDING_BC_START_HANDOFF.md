## 三个新增动作，按此制作

1. **左右侧弯**：先中立→用户左峰→中立、用户右峰→中立。主要由腰/躯干控制，骨盆和双脚稳定，头颈自然跟随。不能绕脚踝把整人当木板倾斜；侧手沿腿外侧下滑，不拉长手臂。原围裙图案保持形状。最终左右各5s：1.5s进入、2s停、1.5s回正。
2. **耸肩**：肩部抬起→轻停→放松，头顶/脸保持稳定。若抬 chest 会连头一起移动，要补偿颈/头，不用抬整条手臂代替耸肩。最终10s：1s抬、4s停、1s落、4s放松。先在170px实际尺寸判断动作是否可读，不能又只追求小角度而看不见。
3. **低位开胸**：双臂在低位稍打开、肩后下、再放回。用现有连续长袖和适合朝向的手型，不后仰、不夸张高举、不缩放袖子。B/C共用一份15s动作：1.5s进入、12s轻持、1.5s回正。

关键姿势静态检查后继续制作短循环与衔接，不必为每一步等待口头批准。正式尺寸与放大版一起看；脚固定、袖根连续、手腕自然、服装不变形是各动作验收的一部分，不能只做数值闭环。
