# 膝外侧凹口：局部修形验证与回交

2026-11-07。已查看 knee-march-evidence、actual、heel-regression 和逐行轮廓数据，使用动画侧当前独立 rig 做了可复现实验。未编辑动画侧 builder、原纹理、v1/v2素材或正式游戏。

## 先纠正位置与结论

- 凹口确实位于远离身体中线的外侧：左腿屏幕左缘、右腿屏幕右缘。之前反馈中的“内侧”用词不准确，以这次坐标为准。无需将 ART-KNEE-L-01 改到另一侧。
- 当前几何在给定骨骼运动下形成凹口，这个定位成立；但“加宽两组权重带没有变化”不能推出“所有修形都无解、只能补画”。控制轮廓的手段还包括姿态驱动的局部网格修形。改变局部几何并不必然要求重画纹理。
- 因此暂不把中立膝部永久加粗12–14px；先采用下面已验证的局部修形，保留中立外形和接地基准。不是要求动画侧再盲试一遍同样的权重带。

## 已完成的隔离方案

脚本 `tools/probe_activity_knee_corrective.py` 读当前 `tools/_debug/activity_spine/activity_standing.spine-json`，输出单独的 `activity_knee_corrective_spine`。增加四个局部修形控制骨（分别跟随左右 thigh/calf），不替换原腿骨轨迹：

1. 只让膝**外侧半边**的顶点分担修形控制的权重；内侧、脸、衣服和手不受影响。
2. 纵向范围围绕膝局部 y=-63，使用有限范围的平滑衰减，离膝约32个源单位以外归零，避免改到袜口、踝和鞋。
3. 屈膝峰值17源单位的外推上限，随屈膝角平滑进入/退出。父骨已旋转时，把所需的屏幕水平方向位移转换回父骨局部坐标，不让修形把轮廓斜着推走。
4. 中立时修形为零；没有腿部屈膝的动画显式保持修形为零，避免后续切到喝水/待机/提踵时残留。

这是局部轮廓调整，不是拉长整条腿、不改骨长、不移动鞋，也不是把源图整块缩放。纹理坐标和绘制内容保持原样。

## 动画侧接下来如何处理

1. 先看修形对照与三轮预览，接受该轮廓方向后，把脚本中的有限范围权重分担和局部修形控制合入自己的 builder；不要只把这份 debug skeleton 拷贝成正式版本。
2. 保持 normal / heel 变体的相同网格与权重规则，其他clip补修形清零。保留当前原骨轨迹、--heel-v2和接地参数。
3. 合入后复验单脚、双脚三轮与提踵换图。当前只是此运动范围内的修形验证，不代表任意深蹲/大幅屈膝都能使用。
4. 如轮廓方向仍不合适，再具体讨论修形幅度/范围或补绘局部膝部；不再把“只能补图”作为已证明结论，也不继续要求重复尝试同样的权重带。

## 袜踝问题：独立保持未关闭

已目视确认 `heel-regression-evidence.jpg` 仍有袜筒下沿台阶、白袜接片感和鞋面色调切换。它们与膝凹口不是同一问题，接地稳定不能作为通过依据。局部膝修形不改鞋纹理，也不会顺带解决这些美术差异。

后续袜踝修复应统一normal/heel重叠处的袜筒轮廓、鞋面色调/高光，明确对接区域和UV对应；不能仅用alpha截窄丢掉描边，也不能用整只脚移动掩盖接片。该项需要单独美术处理与换图前后目视复核，目前没有宣布修好。
