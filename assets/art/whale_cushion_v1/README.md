## 尺寸与接入

生成器实际输出 **1254×1254 RGBA**，不是需求中的 1024×1024；原图已保留。导入/构建时按 registration.json 等比注册到 1024 画布，不能直接当作已配准立绘使用，也不要为凑宽高非等比拉伸。已检查透明通道和主体范围；边缘在实际装配与图集输出后仍需目视检查。

坐垫整体放在坐姿身体后面，先作为一个刚性附件。画身体时让臀侧落在尾鳍上、肩背贴住鲸鱼头/背的坡面，鲸鱼头要从人物侧后方露出；不要将人物整个压在鱼头上。接触位置需以组合草图确认。当前不添加坐垫弹跳或变形。
