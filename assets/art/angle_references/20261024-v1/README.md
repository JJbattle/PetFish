# FishPet 侧身与仰头补画交接

## 文件与用途

| 文件 | 实际尺寸 | 用途 |
| --- | --- | --- |
| `pet_front_reference.png` | 1024×1024 | 原始正面立绘副本，作为身份、服装与骨架坐标基准 |
| `pet_front_to_r34_reference.png` | 1254×1254 | 接近正面的轻微向右转头，作为转身起步的中间角度候选 |
| `pet_r34_reference.png` | 1254×1254 | 朝画面右侧的四分之三侧身，供两个展示动作共用 |
| `pet_up_reference.png` | 1254×1254 | 朝右自然仰头、闭眼，露出下巴和颈前，供喝水头部使用 |

生成方式：内置 image_gen，参考原始立绘及此前五姿态示例。完整提示词见 `PROMPTS.md`。只把最终选择的三张补画放入本目录；前期方向错误或角度过大的候选未采用。

## 已完成与交付边界

三张是各自独立的透明背景合成参考图，已经绘出侧向五官、发型、身体轮廓，以及仰起时露出的下巴和颈部。为方便检查结构，双臂自然下垂，仰头图没有杯子遮住脸。

已目视核对朝向、全身完整性、双手数量、仰头轮廓；文件检查为 32 位 ARGB，角落 alpha 为 0。**尚未交付逐部件独立图层、精确锚点配准或完成绑定的 Spine 资源。** 没有替换原立绘、当前 atlas 或运行时骨架，也未启动 Godot。

`ART_BRIEF_THREE_VIEWS.md` 要求的 1024×1024 是接入目标；生成器实际输出 1254×1254，不能假定它已经严格遵守颈根、肩、腰等像素坐标。各图的角色位置、局部比例、衣褶和发饰细节仍有差异，不能直接将整张图按同一个原点切换。

## 给大肥鱼的接入顺序

1. 以原始 `pet_portrait.png` 和现有骨架为定位基准。在美术编辑器中将补画等比配准到 1024×1024 画布，分别检查颈根、腰和脚底；仅统一画布尺寸不足以完成配准。需要调整骨点时记录偏移，不为硬贴旧坐标把侧脸拉歪。
2. **先锁定 `pet_r34_reference.png` 的侧身身体为一个公共版本。** 仰头时优先只替换 `pet_up_reference.png` 中需要的头脸和颈部，不整张替换，以免裙子、围裙、四肢和鞋跟着变化。五官、衣料花纹及鲸鱼标志应统一，标志沿用项目中已有的正确源素材。
3. 拆出头脸、颈部、前后发、身体与双臂，补齐互相遮住的底层。相邻关节留下重叠边，统一描边、发饰和脸型，清理透明边缘。眼、嘴仍需整理为独立表情附件；闭眼仰头合成图本身不是独立眼睛层。
4. 从正面到侧身先比对中间角度；如果仍有明显跳变，继续补必要的过渡附件或调整姿势。不要宣称三张图天然构成无跳变的逐帧动画，也不要用整脸交叉淡化遮住角度不连贯。
5. 先完成一条喝水链：胸前双手抱杯 → 抬杯贴嘴 → 仰头抬杯底 → 喝一口 → 放杯回正。杯子与双手另做独立层；无杯仰头图用于提供下巴、颈部和嘴的位置，喝水接触样板可参考 `../../pose_references/fishpet-five-poses-20261024-v1.png`。
6. 验收颈部不断开、杯沿贴嘴、手腕连袖口、全程只有两只手。侧身轮廓需纳入 Windows 的窗口显示区域。随后再复用侧身素材完成两个展示动作。

最终先交付配准后的关键姿势图，再交完整动作。当前图的目的是补足原正面图里不存在的角度信息，接入工作以 `SPINE_FIVE_POSES_GUIDE.md` 和真实骨架为准。
