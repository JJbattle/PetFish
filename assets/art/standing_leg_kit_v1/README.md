## 这次交付什么

- 左右裙下大腿补绘；连续腿母件保留完整膝部宽度，不在膝位横切。
- 上下腿重叠拆件、独立鞋、连续整腿母件，均带精确原画裁切坐标。
- 裙内衬，以及保留原前裙边、移除旧腿后的身体层；附逐腿移除遮罩。

脸、头发、头饰、身体服装、围裙、尾巴没有重新生成。只用内置 imagegen 生成裙下隐藏大腿与内衬，提示词见 `PROMPTS.md`。可见皮肤、袜口、袜筒与鞋直接从**正式站姿当前实际使用**的 `rig_repair.registered(front_armless_v1.png, .78, (31,28))` 取像素；这是 `build_spine.py` 的 `repair_layers()` 所用贴图，避免换回另一版腿脚造成新的造型差异。原始角色母版仍是 `pet_portrait.png`。

`assembly.json` 是装配真值：每张 PNG 的 `source_rect` 为1024原画坐标、左上包含右下不含；PNG 已带4px安全边。按 `position_top_left` 原尺寸贴回，不再依照图像包围盒单独缩放。若 Spine 需要 region 中心，使用裁切框中心，再转换到所属骨骼局部坐标。

## 关节坐标纠正

- 保留现有髋 `(442,720)/(500,720)`、踝 `(432,905)/(520,905)` 作为旧 rig 参考。
- y800 是待加膝骨的**隐藏关节参考线**，不是可见袜口；当前源图袜口花边约在 y839–861，鞋面约 y880 开始，y905 是现有骨/附件切线。
- 本补件 y800 的轮廓中心约 `(438,800)/(523.5,800)`，仅作为新增膝骨定位建议，尤其不要直接把右髋 x500 当右膝 x。需结合新骨链与姿态复核。
- 已验证的连续网格、smoothstep、膝修形、同源鞋和踝部连续权重**方法可以复用**；旧活动角色的局部 −40…−86、控制骨位移量、左右符号/轴向必须按新骨坐标重算，不能连数值照搬。

## 裙边 / 身体接法

当前 `cut_legs()` 以 y800 整条水平切分，连裙边/其它下方像素都进入腿槽，并在 body 填成深色。**本包接入时要替换这一步，不能在其结果上继续叠新腿。**

可直接以 `front_body_without_legs` 替代旧 body 的对应纹理（来自同一前置原图，不包含旧深色填洞），或在 `repair_layers()` 后用移除遮罩生成同样结果。前后顺序：腿/鞋 → 裙内衬 → 现有前身体/前裙。其它前后层级沿用正式 rig，保留喝水第4版袖子和现有角色槽位。

普通鞋没有补画，也不需要异色 heel 图。提踵时须在新坐标系验证前掌接触点；不能把踝骨当作前掌旋转中心，亦不要未经回归照抄旧角色的抬升量。
