# 鲸鱼垫坐姿写字：拆件与装配说明

2026-10-30。此目录是当前可交接的完整静态装配包。已将七张透明层实际拼回角色，提供明暗背景检查图、数值坐标和 Spine 4.2 静态起稿。尚未制作动作、运行时网格权重或更新正式 working。

## 先看哪些文件

先看 `assembled-light.jpg` 和 `assembled-dark.jpg`，再看 `parts-overview.jpg`。`assembled.png` 是七层实际拼装的透明结果，不是生成工具重新画的效果图。`assembly.json` 是位置的唯一数值来源；`anchors.jpg` / `anchors.json` 是供绑定校对的解剖位置参考。

## Spine 4.2 中复原

1. 新建独立工程，使用数据导入 `seated_setup.spine-json`，图像目录指向本目录。它是 JSON 静态骨架数据，不是 `.spine` 工程，不是现有游戏的替换包；还没有 `.atlas`、动作或 IK。
2. 导入后与 `assembled-light.jpg` 核对。JSON 已处理坐标转换：Spine 的 y 和旋转角取屏幕值的负数。只在导入前转换一次，不要再反转第二遍。图像宽高已包含表中静态缩放，骨骼 scale 保持1，避免重复缩放。
3. 起稿结构是 `root → sit_body → sit_head / book_lap / arm_far / arm_near_pen`，坐垫直接挂 root。七个 slot 按上表排序；两层头发/头部共享 sit_head。
4. 先确认静态姿势完全正确，再把 sit_body 支点调整到腰附近，并保持附件和子骨骼世界位置不变。参考点是近肩(650,615)、近肘(663,732)、近腕(730,792)、笔尖(817,858)、远肩(850,620)、远肘(878,709)、远腕(935,779)。这些是目视估计，绑定时必须在原图上复核，不是已解算好的 IK 参数。
5. 两条手臂各建立上臂→前臂→手骨，把连续袖子附件转换为网格：肩根少量权重留给躯干，上臂/前臂主体各跟相应骨，肘部只做局部过渡。手掌和笔保持刚性，不能用整个手臂缩放替代屈肘。
6. 握笔手与笔在同一张图里，第一版通过手骨一起控制，避免笔从手里滑走。若以后需要松笔、换握法或独立转笔，需补完整笔和无笔握持手，不能直接把握持处剪出透明洞。当前素材支持小幅写字，不支持这些变体。
7. 书本保持刚性；在书本坐标系中设置笔尖轨迹，再由手臂关节跟随。小范围短笔划、停顿、换行即可，先从2～4个装配像素试起，逐帧确认笔尖贴纸；不能让手、笔和本子分别随机摆动。

本轮只验证了 JSON 层级、文件引用和静态变换，未在 Spine 编辑器或运行时导入验证；导入发现差异先与 manifest 比对，不绕过检查直接覆盖生产骨架。

## 接入游戏前

- 当前装配画布1280，与现有游戏参考画布不同。先按站姿的实际头部大小确定整套等比尺度，再对齐脚/坐垫接触底边；整体转换所有关节、附件和轮廓。不能为了塞进“坐高520～580”而单独缩头或压扁角色。最终站坐切换的尺寸一致性尚待运行时验收。
- 新包不包含站到坐、收本起身的过渡。先单独验收坐姿写字循环；更大幅动作缺素材就列补图需求，不拉伸站姿或交叉淡入两套手。
- 正式 working 及“记两笔”入口继续共用同一状态映射。坐姿包完成前保留现有行为。展示菜单、提醒、喝水等与本包无关的动作不可回退。
- 重建全动作轮廓并集；坐姿更宽，要检查气泡、设置卡片及点击穿透范围。只使用隔离、非置顶、限时的预览进程，失败结束自己的进程。
- 视觉验收包括明暗底、原画放大及实际桌宠尺寸；检查肩根、袖口、纸面、头发分层边界和坐垫接触。随后再检查循环首尾、极限姿势和切换前后一帧。

## 重现与交接

仓库根目录运行 `python tools/prepare_seated_kit.py` 可从母版重新导出本包、数值配置与检查图。脚本只操作此素材目录，不运行桌宠或更新正式图集。绘画使用内置 imagegen，提示见 `PROMPTS.md`。素材归属与许可沿用仓库 README。

给大肥鱼：先导入静态起稿并复原检查图，再绑定手臂网格，最后制作短笔划循环。不要重新猜坐标，不要额外画手，不要再把长袖切成互不重叠的碎片。请提交实际运行时截图与动态预览后，再接到正式 working。
