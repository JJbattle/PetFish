## 准确时间线

### 小鱼看看两边

| 时间 | 内容 |
| --- | --- |
| 0–5 s | 坐稳准备，双脚平放，双手放大腿 |
| 5–17 s | 头缓慢转向用户左侧，再回正 |
| 17–29 s | 头缓慢转向用户右侧，再回正 |
| 29–41 s | 头轻轻侧倾向用户左侧，再回正 |
| 41–53 s | 头轻轻侧倾向用户右侧，再回正 |
| 53–60 s | 回正放松 |

每个 12 秒段可按 3 秒进入、5 秒轻停、3 秒回正、1 秒中立制作。各方向只做一次，段长包含过渡，不额外加时。左右采用用户视角的镜像示范（屏幕左=用户左）。转头是绕颈部竖轴旋转、头部不歪；侧倾是耳朵向肩膀方向轻靠、仍看向前方。手不拉头，肩膀不向上迎头，不做完整绕颈圈。舒适范围优先，分镜角度不是用户必须达到的目标。

### 肩膀松一松

| 时间 | 内容 |
| --- | --- |
| 0–5 s | 坐稳准备 |
| 5–21 s | 轻耸肩再慢慢放下，8 秒 × 2 次 |
| 21–37 s | 小幅缓慢向后绕肩，4 秒 × 4 次 |
| 37–53 s | 肩膀轻轻向后向下，8 秒 × 2 次 |
| 53–60 s | 双手回大腿，自然放松 |

耸肩周期建议 1 秒抬肩、3 秒轻停、2 秒放下、2 秒放松。图 02/03 是同一动作的抬起和放下，不是两个独立时段。后绕肩只动肩带，双臂低位，不画成手臂大绕圈。肩胛后收周期建议 1.5 秒进入、3 秒轻停、1.5 秒放松、2 秒中立；胸口轻展，躯干不后仰，不夹背到极限。

## 给大肥鱼的动画衔接补充

1. 沿用根目录 `SPINE_ACTIVITY_HANDOFF.md` 的暂停、手动结束、闹钟优先、安全收尾、明确确认才记录规则；坐姿增加独立模式 `seated_mobility`，完成只记录“坐姿舒展”，不调用 `stand_up()`，不重置起身计时、不替代待处理的起身提醒。
2. 默认作为“暂时不方便起身”的可选跟练或主动入口。若从久坐提醒进入，仅暂停它的舞台展示；返回后仍可选择站立活动、稍后或原有明确处理提示的操作。不能因选了坐姿就静默删除提醒。
3. 新增建议前缀 `activity_seated_`：`neutral`、`ready`、`turn_user_left/right`、`tilt_user_left/right`、`shrug_cycle`、`shoulder_roll_cycle`、`scapula_cycle`、`relax`。所有周期从坐姿中立开始、回到同一中立，60 秒包含准备/过渡/收尾。
4. 先补专门坐椅子的身体/腿部与放大腿的双手，不把现有鲸鱼坐垫盘坐/写字图硬拉成椅上坐姿。椅子固定、四脚稳定、双脚平放地面，不悬空或盘腿；头高比例沿用 `docs/POSE_HEAD_SCALE.md` 的统一思路重新测量，不把新画布总高直接当角色头高。
5. 当前工作坐姿头部连长发且有配套下巴遮挡片，不可只旋转下巴或压缩脸做侧转。需要左右转头时补匹配的头脸/颈部/头发及遮挡；侧倾仅轻微旋转头颈，肩膀、椅子和双脚稳定。长发不穿椅背，不跟肩绕圈，袖口不裂开。
6. 开始前妥善收好本子/笔/杯子，切到新坐姿。没有自然坐下/起身的中间素材时，沿用现有姿势切换能力并注明缺口，不承诺已做自然过渡。动作条显示简短提示、方向和倒计时；头转向旁边时不要要求用户持续盯屏确认。
7. 取消/暂停时头回正、肩放下、双手回大腿；中断返回后重新计算基础会话状态。锁屏/休眠/过大帧间隔自动暂停，不自动完成。
8. 正式接入前分别验收放大与实际尺寸、头颈连续转向、左右镜像、双脚/椅子锚点、三轮衔接、中断恢复及轮廓。只用隔离、非置顶、限时预览。当前仅静态出图，未绑定/测试动态，不把原图六格裁片当序列动画。

## 动作资料与出处

短版 60 秒节奏是本项目产品编排，非临床训练处方。转头/轻侧倾参考 [NHS inform 颈部活动示范](https://www.nhsinform.scot/illnesses-and-conditions/muscle-bone-and-joints/neck-and-back-problems-and-conditions/exercises-for-neck-problems)；耸肩/后绕肩参考 [CCOHS 工位活动](https://www.ccohs.ca/oshanswers/ergonomics/office/stretching.html)；轻开胸参考 [Mayo Clinic 办公室上肢拉伸](https://www.mayoclinic.org/healthy-lifestyle/adult-health/multimedia/shoulder-stretches/vid-20084699)。通用提示保持正常呼吸、轻缓动作，疼痛或头晕立即停止；已有颈部伤病或症状者先询问专业人员适合的范围。
