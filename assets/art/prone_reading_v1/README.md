# 趴着看书素材包 v1

此版已归档。后续趴读动画请使用 [v2 素材和装配说明](../prone_reading_v2/kit/ASSEMBLY_GUIDE.md)。

用户授权继续下一个动作后，按队列补画的独立趴姿。交付入口：

- `kit/assembled-light.jpg`：六个透明拆件实际拼装预览。
- `kit/ASSEMBLY_GUIDE.md`：装配坐标、层级、动作限制与接入验收要求。
- `kit/prone_setup.spine-json`：静态摆放数据，未在 Spine 编辑器实测；无动画。
- `kit/PROMPTS.md`：内置 imagegen 提示词与素材来源记录。
- `parts_sheet.png`：1536 × 1024 分层母版。
- `pose_draft.png`：废弃姿势草稿，含重复尾巴，不作为目标。

本次只准备素材与交接文档，不修改生产骨架及当前坐姿动画。复现脚本为 `tools/prepare_prone_kit.py`。
